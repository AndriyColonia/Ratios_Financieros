## 2. Los 14 ratios y cómo se leen
| Familia | Ratio | Fórmula (curso) | Mayor que el sector significa |
|---|---|---|---|
| Liquidez | Liquidez corriente | Activo corriente / Pasivo corriente | Más holgura; demasiado alto = dinero ocioso |
| Liquidez | Capital de trabajo | Activo corriente − Pasivo corriente | Más colchón de corto plazo |
| Solvencia | Endeudamiento (P/C) | Pasivo total / Patrimonio | Malo: más dependencia de deuda |
| Solvencia | Cobertura de deuda | Deuda financiera / EBITDA | Malo: más años para pagar la deuda |
| Eficiencia | Días de inventario | Inventario promedio / (costo de ventas / 365) | Malo: producto parado |
| Eficiencia | Días de cobro | Cuentas por cobrar promedio / (ventas / 365) | Malo: cobra lento |
| Eficiencia | Días de pago | Cuentas por pagar promedio / (costo de ventas / 365) | Más plazo con proveedores (da caja); muy alto puede indicar presión de liquidez |
| Eficiencia | Ciclo de efectivo | Días inventario + Días cobro − Días pago | Malo: más días que financiar |
| Rentabilidad | Margen bruto | (Ventas − Costo de ventas) / Ventas | Bueno |
| Rentabilidad | Margen operativo | Utilidad operativa / Ventas | Bueno |
| Rentabilidad | Margen neto | Utilidad neta / Ventas | Bueno |
| Rentabilidad | Margen EBITDA | EBITDA / Ventas (EBITDA = utilidad operativa + depreciación y amortización) | Bueno |
| Rentabilidad | ROA | Utilidad neta / Activo total promedio | Bueno |
| Rentabilidad | ROE | Utilidad neta / Patrimonio promedio | Bueno |
| Rentabilidad | DuPont | ROE = Margen neto × Rotación de activos × Apalancamiento | Descompone el ROE |

Notas: días = 365 / rotación (son lo mismo, se prefieren días porque se leen como tiempo). Líder = menor valor en días, ciclo y deuda; mayor valor en márgenes y rentabilidad.
